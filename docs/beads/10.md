## What
Assemble the coach's race knowledge from config instead of literal prose, in one shared module `scripts/coach-prompt.mjs` imported by both `scripts/coach.mjs` (`SYSTEM_PROMPT_TEMPLATE`, line 82) and the chat endpoint `CHAT_SYSTEM` in `web/vite.config.ts` (~196-294; it currently cannot import from scripts — solve with a dynamic `import()` at request time like `facts.mjs` is already imported at runtime). The race paragraph is built from race.json: name, distance, gain, date + weekday in race timezone, location, cutoff, elevation range, `features`, and each `coach_notes` section verbatim. Facts gain `race.aid_stations` (name, mile, cutoff_h, crew/drop_bag/pacers), `race.features`, `race.elevation`, and `history[]` (archived races: name, date, `result.json` summary, top 3 `agent_notes` mentioning it). In generic mode the goals paragraph from the goals bead is used. Altitude: when `elevation.altitude_significant`, the prompt states the acclimation/arrival-timing demand.

## Why
The agent has never been told the course structure (only a 13-station name list); the two prompts drift ("KEEP IN SYNC" comments); every Mogollon-specific clause must come from the folder.
