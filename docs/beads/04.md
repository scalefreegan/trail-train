## What
Render generic mode in the web client. When `useActiveRace()` returns `{active: null}`: the command bar shows no short code and no countdown chips; view chips for `race` and `nutrition` are hidden and `view` falls back to `training`; `RaceRibbon` is not rendered; `Trajectory` plots a rolling 12-week window with no "RACE" marker; `RoadAhead` labels weeks by calendar date instead of "Race week". With a race active, everything reads from the payload and `DEFAULT_RACE` / `DEFAULT_BLOCK` in `web/src/data.ts` are deleted.

## Why
Today there is no null-race path in the UI; every panel assumes `race.date`, `race.cutoff_h`, `aid_stations`.

## Acceptance Criteria
- Delete `DEFAULT_RACE` (`web/src/data.ts` ~70-95) and `DEFAULT_BLOCK` (~136-161); `useBlockConfig` becomes a thin adapter over `useActiveRace()` returning `{ race: RaceConfig | null, block: BlockConfig }`.
- `APP_VIEWS` (`web/src/App.tsx` line 114) is computed from the active race's `features`; a persisted `view` of `race` with no race active resolves to `training` without a console error.
- `CommandBar` (~117), `RaceRibbon` (~368), `Trajectory` (~687, "RACE" marker ~880, wk20 labels ~962/1072), `RoadAhead` (~1021, "Race week" ~1181-1229): all conditional on `race != null`; no `race.` access without a null check (tsc must pass with `strictNullChecks`, already on).
- Trajectory in rolling mode: x-axis is the last 12 ISO weeks, cumulative actual vs the rolling targets from facts; the "projected wk20" stat becomes "projected this week".
- Recommendation string at `web/src/data.ts` ~614 ("MM100-relevant grade") is derived from the race short or dropped in generic mode.
- `web/index.html` title is "Basecamp"; `macos/Basecamp.applescript` line 41 health check matches "Basecamp" (rebuild via `macos/build-app.sh` and note in `macos/README.md`); footer at `App.tsx` ~2103 no longer says "mogollon bound".
- `npm run build` (tsc + eslint + vite) passes.

## Technical Context
- Providers: `web/src/providers.tsx`, `StateProvider` feeds `useBlockConfig`.
- The race payload hook from the schema bead.
- Weekly bucketing must match `scripts/facts.mjs` rolling-window definition (same ISO-week start).

## Constraints
- Keep the existing dark theme and layout; this is gating, not redesign. No new dependencies.

## Out of Scope
