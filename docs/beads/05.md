## What
Remove every remaining race literal from code so that `grep -ri "mogollon\|MM100\|pine, az\|rim 6\|horton\|buck springs\|fish hatchery\|two-sixty\|old pine" scripts web/src web/vite.config.ts macos README.md` returns nothing outside `races/`. Make `scripts/build-course.mjs` take a race folder (`node scripts/build-course.mjs --race <slug>` defaulting to the active race), read `course.gpx` + `race.json` from it, and write `build/course.json` and `build/crew-base.json` inside the folder; the dev server serves the active race's `build/course.json` at `/course.json` so `useCourse` keeps working.

## Why
Literal strings are how the last race leaked into the prompts, the crew sheet, and the Mac app health check. The course builder is the only script still hard-wired to a filename.

## Acceptance Criteria
- `scripts/build-course.mjs`: `GPX_PATH`/`RACE_PATH` (lines ~28-29) replaced by folder args; log line ~171 and payload `source` ~438 use `race.name`/slug; `race_climbs` accepts any count (ClimbComparison grid in `web/src/race/ClimbComparison.tsx` lays out N climbs, not 6); the `extendStart` comment/heuristic (~246-260) is parameterized or documented as generic.
- `web/src/race/CrewSheet.tsx` literals at ~176, 179, 181, 290, 293 replaced by `race.json.crew_info.start_notes`, `driving`, and `sources` (manual year from provenance); `ClimbComparison.tsx` ~355 title uses `race.short`.
- `web/src/race/nutrition.ts` `DEFAULT_NUTRITION.drop_bag_gear` (~107-112) has no station names; per-race `nutrition.json` supplies them; missing gear for a drop-bag station renders an "unplanned" row, not a crash.
- `scripts/sync-strava.mjs` line ~49 long-run regex reads `profile.long_run_name_patterns`; `scripts/state.mjs` `DEFAULT_CALENDAR_CONVENTIONS` (line ~28) becomes an empty string with the current text moved into the athlete's `state.json` by the v3 migration (coordinate with the migration bead if not yet merged).
- `web/vite.config.ts` port comment ~944 and `macos/README.md` no longer explain the port by the race.
- `README.md` rewritten: "Built for ..." paragraph replaced by the race-folder model; setup section documents `races/`, `config/active-race.json`, `config/goals.json`.
- `npm run course:build` works for the archived MM100 folder and reproduces today's `web/public/course.json` within GPS snapping tolerance (diff station `gpx_mi` ≤ 0.05 mi).
