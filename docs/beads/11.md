## What
Intake stage 1: a dev-server endpoint `POST /api/race-intake` that takes `{site_url, extra_urls[], year, uploads: [{name, path}], notes}` (files uploaded via a multipart `POST /api/race-intake/upload` into a temp dir), streams progress over SSE like `/api/refresh`, and runs a headless `claude -p` intake agent (`scripts/race-intake.mjs`) with `WebFetch`, `WebSearch`, `Read` allowed and a strict JSON output contract equal to race.json minus computed fields (`sun`, snapped `lat/lon`, `race_climbs` metrics). Fetched pages and PDFs are cached under `races/<slug>/sources/` with a manifest. PDFs are additionally rendered to per-page PNGs (use `sips` on macOS, no new deps; fall back to text-only with a warning) so image-only aid-station charts can be transcribed. Output is written as `races/<slug>/race.json` with `status: "draft"` and `provenance.by: "agent"` on every field, plus `sources[]`.

## Why
This is the "plug in a race" step. The San Juan Softie 2026 manual's aid chart is an image; a text-only agent cannot read it.

## Acceptance Criteria
- Running the endpoint against `https://www.sanjuansoftie.com/` with the 2026 manual PDF and the Gaia GPX produces a draft with 11 aid stations, `date` 2027-08-13 (or the year requested), `timezone: America/Denver`, `cutoff_h: 38`, `features.crew/pacers/drop_bags: true`, `features.heat: false`, `elevation.max_ft: 12438`, `links.results` pointing at OpenSplitTime, and `crew_info.station_notes` for Cross Mountain and Ryman Creek.
- Fields the agent could not establish are `null` and listed under `unresolved[]` in the response (never invented); the schema validator from the schema bead runs before writing and validation errors abort with the raw agent JSON saved to `sources/agent-output.json`.
- The endpoint refuses cross-site requests, refuses a slug that already exists unless `{refresh: true}` (re-intake bead), and never touches `config/active-race.json`.
- Agent session limits: reuse the error classification and retry from the chat endpoint (`web/vite.config.ts` ~302-600) — factor it into a shared helper if not already.
- `scripts/race-intake.test.mjs`: contract validation on a recorded agent output fixture; slug derivation (`<name>-<year>` kebab).

## Technical Context
- Headless agent spawn pattern: `scripts/coach.mjs` (`claude -p --output-format json --allowedTools ... --append-system-prompt`), model via `TRAIL_COACH_MODEL`.
- SSE pattern: `/api/refresh` in `web/vite.config.ts` (~41-190).
- Course build is stage 2 (separate bead); nutrition/block/theme are stage 3.

## Constraints
- No API key; local `claude` CLI. No new npm deps. Never write to `web/public`.

## Out of Scope
The dialog UI, course build, block/nutrition generation, merge on re-intake.
