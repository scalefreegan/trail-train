## What
Coach chat gets race context. The client sends a compact `race_state` JSON with each chat turn (projection: goal, per-station expected ETA; knobs; fuel/caffeine summary; block_stale/unresolved/activation; last checkpoint when present); the chat endpoint validates size (≤ 8 KB) and chatSystemPrompt renders it as a short block with a "numbers come from the athlete's own planner" preamble; generic mode sends none. Token cost measured and added to the turn-budget check in agent-run/coach-prompt.
## Acceptance Criteria
- Tests: prompt snapshot with and without race_state; oversize → 400; the readout (coach.mjs) path unchanged.
- Manual: one chat turn in view mode on MM100 renders (this spends one turn — ask the lead before running it).
