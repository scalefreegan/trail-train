## What
Frontend test harness + fixtures. web/tests/ with a Playwright config (uses the cached Chromium; playwright as a devDependency), synthetic fixtures (fake strava/oura/google-cal/coach/state/profile/goals JSON; races/_fixtures/mm-like-100/ with a ~200-point GPX, race.json, built course, nutrition; the crewless 50k), and a launcher that copies fixtures into a temp root and starts vite on a free port with `TRAIL_PROJECT_ROOT=<root>`. The dev server (web/vite.config.ts) and every script that resolves the repo root honour TRAIL_PROJECT_ROOT. agent-run.mjs honours `TRAIL_FAKE_AGENT=<file>` returning canned output (no spawn) so agent flows are testable. Four core flows: generic load (panels present, no console errors), switcher view MM-like → race view → back, review screen save + acknowledge, race-day hold. `npm run test:ui`.
## Acceptance Criteria
- test:ui green locally in < 90 s; fixtures contain no personal data (grep); TRAIL_PROJECT_ROOT covered by a node test.

scratchpad/ui-harness scripts from the interactive rounds are the reference (read /private/tmp/.../scratchpad/review/ui-round*.md for flows); scripts/lib.mjs root resolution; vite.config.ts projectRoot.
