## What
Static crew export pipeline. A second Vite entry web/crew.html + web/src/crew/ that bundles the pure projection code (pacing.ts, nightWindow.ts, clock.ts, checkpointHold) into ONE self-contained HTML (a small inline plugin in vite.config.ts inlines the JS/CSS; no external URLs, no fonts fetched). scripts/crew-export.mjs `--race <slug>` renders the shell with the race data embedded as JSON (course, projection inputs at the current knobs from a knobs file or defaults, fuel plan per crew stop, crew_info incl. crew.private.json when present, map track + profile) to races/<slug>/build/crew-<date>.html; POST /api/races/:slug/crew-export does the same and the race view gets an "export crew page" button that downloads it.
## Acceptance Criteria
- Test: export for the MM100 fixture; the HTML contains no `http(s)://` asset references, opens headless with network disabled, renders station rows; size < 2 MB.
- Build stays green; `npm run build` produces both entries.
