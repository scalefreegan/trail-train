## What
B-race UI. Switcher: B-races grouped under their A-race with "Add tune-up…" opening a quick-form dialog (name, date, distance, gain, optional GPX; "run intake" button optional and clearly marked paid). Trajectory: a marker per B-race at its week with a label. Viewing a B (view mode) opens a reduced planner: station table if a course exists, ETAs, goal knob; crew/drop-bag/caffeine gated off via features defaults for kind b; nutrition view hidden unless nutrition.json exists. useDialog for the form.
## Acceptance Criteria
- Playwright proof scripts (harness at scratchpad/ui-harness): create a B via the form → appears under A → marker on trajectory → view it → reduced planner renders with no console errors; a11y names on all controls.
- tsc/eslint/build/test green.
